## 页面与持久化操作

| 操作 | 预期 | 实际 |
| --- | --- | --- |
| 从教学首页点“对话补充重点”，等待项目目录异步就绪 | 输入框空白、参考卡片保留、未输入时不可发送 | 页面显示“当前事项 · 教学重点”，项目加载前后卡片均在，发送键禁用 |
| 输入合成教学要求，再从教学点“准备下一节课” | 原草稿不覆盖，明确选择新事项 | 原话保持，出现“当前草稿未改 / 带入下一节课 / 不带入”；带入或移除参考均不改原话 |
| 刷新并发送教学要求 | 草稿与参考恢复；模型接收两者；历史以老师原话为主 | 刷新后两者恢复；本地模型收到原话和教学重点参考，没有旧输入占位；消息气泡将参考折叠，侧栏使用老师原话，重进会话后仍一致 |
| 成长模块点“记录复盘” | 不把保存路径和固定操作写进输入框 | 输入框空白，展开参考仅显示“教学复盘” |
| 在“交给 EduPi”输入原话后点“开始协作” | 原话仍可编辑，不被转为页面参考 | 抽屉输入框保留原话；发送到本地模型的 user 内容无页面参考包装 |
| 创建明确标记的合成到期任务，打开提醒并点“继续聊” | 事项参考与老师发言分开，发送后会话绑定且不串原草稿 | 任务参考仅含标题和日期；发送后 Core `taskSessions` 回读同一 session ID；离开再进仍是原会话，切回普通对话时原未发送草稿保持 |
| 从提醒会话切到普通会话 | URL 不残留提醒任务身份 | `task` 参数已清除，普通会话草稿仍在 |
| 教学参考与旧草稿未发送时，从今天提交另一条教师要求 | 不自动混合、覆盖或夹带旧参考 | 显示旧草稿未改与三种明确选择；发送禁用。重载后待选择内容、旧草稿及旧参考均保留；点“改用新要求”后旧参考消失，仅新要求进入输入框 |
| 模型运行中从教学入口附参考、写后续消息并排队，再点“移回输入框” | 排队列表和收回内容都只显示老师原话，参考可恢复 | 排队行显示“把这节课的例题按学生水平重排。”，无协议包装；收回后输入框恢复该原话，“教学重点”仍为单独参考卡片 |
| 运行中先排队、再写另一份草稿并收回 | 队列不自动覆盖或混合未发送草稿 | 显示“已收回 1 条后续消息，当前草稿未改”；重载后两者保持；明确点“追加到当前草稿”后才合并 |
| 先同步保存队列副本，再发清队列命令 | 立即刷新或切会话不丢失、不串入另一会话 | 隔离页面完成“排队 → 收回 → 立即刷新”，旧草稿与待恢复消息均回读；注入延迟清队列并切会话的测试将结果落回原会话，存储失败时根本不发清队列命令 |
| 清队列时新增消息、丢响应、服务端异常与确认丢失 | 不能因为客户端快照过时而丢新消息，也不能重复清空新队列 | 服务端在同一同步栈完成快照、私有 flushed 文件与清除，以请求 ID 幂等重试；清除后本地完整落盘才 ACK，服务端改成不含正文的 tombstone。空队列/准备中异常保留待核对副本，不自动二次发送；quota 失败不 ACK，双击收回只执行一轮 |
| 新建对话附教学参考后执行 `!pwd` | Shell 命令不发给模型，参考不随会话晋升丢失 | 页面显示 `bash pwd`，命令结束后输入框空白，“教学重点”参考卡片仍在 |
