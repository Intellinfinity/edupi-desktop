- 本机从 v0.3.29 点击应用内更新两次，都在清单检查阶段得到 `UPD-227408f2`；该码精确对应 `plugin updater not found`。v0.3.29 可执行文件没有内嵌 updater 公钥，无法自行完成升级。Raw 清单在直连和 7897 代理下均返回 HTTP 200，因此这两次失败不是网络下载故障。

- 已把本机 `/Applications/EduPi.app` 恢复为原 v0.3.29，Core/投影/Kernel ready，51 学生、240 任务、43 校历、9 课表及认证、模型、设置文件 SHA-256 与升级前相同。故障 v0.3.34 应用作为诊断证据保存在 `/private/tmp/edupi-v034-failed-evidence.TBRlYb/EduPi-v0.3.34-startup-failed.app`，`/Applications` 只有一个 EduPi.app，没有改动教师数据。
