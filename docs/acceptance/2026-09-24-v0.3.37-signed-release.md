## 本机旧版基线与剩余验收

- `/Applications/EduPi.app` 仍为唯一已知安装副本 `0.3.36`；它的 Core `860594a…`、投影与 Kernel 为 ready，工作区回读 51 名学生、240 任务、43 校历、9 课表，`externalSend=false`。模型、认证、设置文件升级前摘要已在当前任务中记录，不把原始密钥写入仓库。已安装版 `/api/updates?refresh=1` 返回当前 `0.3.36`、最新 `0.3.37`、`updateAvailable=true`。
- Mac 锁屏使原生窗口无法操作，因此没有点击更新、下载验签、替换、自动重启或升级后数据/配置回读；这部分仍为“已实现待验收”，不因公开包或更新检测通过而勾选。Windows/Linux 旧版应用内升级也未由干净安装替代。
- AI 协作输入、OCR/逐项日程与课表来源配对尚未在签名安装版用真实教师材料与真实模型逐项验收；R21 通知点击、睡眠补跑、Safe Mode 故障插件恢复与 R23 JEV 受管浏览器/OpenConnector 受管 runtime/Core grant/Receipt 也继续未验收或未实现。手机异地 HTTPS 服务按路线图最后实施。
