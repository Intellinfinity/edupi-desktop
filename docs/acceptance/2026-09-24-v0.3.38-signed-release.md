## macOS 签名与公证

- 正式 runner 在签名后的应用上启动 packaged runtime，验证 updater 公钥，随后完成 DMG 公证、staple、Gatekeeper 和重新下载核对。
- 本机从公开 Release 独立下载 DMG 并挂载。`codesign --verify --deep --strict --verbose=2` 返回 valid on disk / satisfies Designated Requirement；`spctl -a -vv --type execute` 返回 `accepted`、`source=Notarized Developer ID`；`codesign -dv --verbose=4` 显示 Developer ID `BY3XZG2839`、Hardened Runtime 与 `Notarization Ticket=stapled`。
- 本机对 DMG 直接执行 `stapler validate` 仍因 Apple CloudKit TLS `-1200` 无结论，`spctl --type open` 因缺上下文返回 `Insufficient Context`。这两项不记为通过，也不覆盖 runner 的 DMG 验证和挂载后 `.app` 的独立成功结果。
