## 更新代理与 Windows 风险修复

- 设置只接受 `http://127.0.0.1:<port>`，拒绝远端主机、TLS 代理、凭据、路径、查询和无效端口；保存到独立 `updater-proxy.json`，不修改教师数据根或模型配置。损坏配置 fail closed，可明确恢复系统网络。
- Tauri updater 把同一代理用于签名清单与资产下载；服务端 GitHub Release 检查只为单次请求创建/关闭 `ProxyAgent`，不修改全局 dispatcher，不影响 Core 或模型流量。
- 对原 PR #251 的复审发现 Windows `std::fs::rename` 无法覆盖已有目标。PR #255 合并为 `acd7ae4`：Windows 使用 `MoveFileExW(MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`，macOS/Linux 保持同目录 rename。Windows runner [`35976790629`](https://github.com/Intellinfinity/edupi-desktop/actions/runs/35976790629) 编译通过；正式 Windows release 的 Cargo/原生测试和打包也通过。
- 本机显式以 `http://127.0.0.1:7897` 请求 GitHub Latest API 返回 HTTP 200；这证明当前 VPN 代理可达，不等于尚未保存该设置的旧安装版已通过代理更新。
