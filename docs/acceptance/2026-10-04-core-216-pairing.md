## 未验与保留边界

本次未构建新安装包、替换 `/Applications/EduPi.app` 或更新 feed；两者回读仍为 v0.3.45。源码版本号未作为新签名候选发布；后续打包必须使用新版本和精确配对身份。

现有发布/预览安装 Core 使用 `npm ci --ignore-scripts`，不会运行新 postinstall。Core 打包清单不含 Pi SDK 树，模型 host 使用 Desktop 自身已修补的 SDK，因此本轮没有盲目改变发布流程；新包仍须逐字节核对清单内 Axios 和实际 Desktop host 依赖，不能把本机 Core 安装通过当作包内树已验。

新 pin 的 macOS 页面/安装、Windows、真实跨到期睡眠、真人教学质量和六领域 Live 未由本轮服务测试证明。#216 未实现 A1 暂缓产物只读合同；既有拒绝边界不变。
