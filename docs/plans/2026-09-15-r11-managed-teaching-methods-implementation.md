# R11 受管教学方法实施计划

## Core

1. 新增有界、严格校验、幂等的教学方法 store，覆盖 create、update、record trial、validate、publish 和 retire。
2. 验证试用所引用的任务与产物，生成可追溯教师成长投影。
3. 合并受管方法与旧只读 evolution 投影，保留旧冻结策略。
4. 将已发布方法正文和版本加入 G1 Harness input、live model prompt 与来源指纹。
5. 更新 bridge 错误映射、writer matrix、component manifest 和针对性回归。

## Desktop

1. 严格校验教学方法 mutation 请求与 Core 响应，使用确定性 request ID。
2. 扩展生命周期 client contract，接入 revision、可用动作、任务/产物试用证据和教师成长。
3. 在成长页完成新增、修订、试用反馈、验证、发布与停用，并在成功后原子刷新投影。
4. 在教师成长表显示真实反馈并链接统一任务详情。
5. 添加组件和 API 回归，随后跑 TypeScript、ESLint、全套测试与独立审查。

## 真实验收

在隔离数据根启动真实 Core 和 Desktop，创建一项教学方法，绑定真实备课任务完成反馈、验证与发布，再触发一个匹配备课任务并捕获模型输入。刷新和重启后复核生命周期、成长记录和方法复用；最后修订方法，确认新正文重新等待试用。
