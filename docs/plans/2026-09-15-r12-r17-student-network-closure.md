# R12/R17 学生双网络收口

## 已有能力

学生记录已经由 Core 按稳定学生 ID 保存，支持同名、转班、来源对话、日期筛选、知识点别名、修改、历史恢复、删除和20条分页。学生详情可直接切换知识图谱与人际互动网络，班级名单已有24人分页和61人页面证据。

## 当前缺口

- 网络图只接收列表当前页的20条记录，无法逐层查看更大的关系集合。
- 点击学生或知识点只改变线条透明度，没有把目标和关联记录移入当前视野。
- 日期输入可筛选任意范围，但没有使用已导入学期周次的一键筛选。
- 人际互动图仍使用通用“知识点”图例，较难分辨学生、互动事件和活动主题。
- 尚缺大图加载、聚焦、键盘选择、修订删除后图/表同步的同一轮页面证据。

## 实现

1. 将单次图谱窗口从20条提高到60条，并保持100名参与者上限；超过当前窗口时由老师每次加载20条，不一次性渲染全量数据。
2. 列表继续按20条翻页。网络图从第1层开始，显示已加载数与总数，并提供“加载更多”。筛选、学生、网络类型或时间变化时重置窗口。
3. 学生、记录和主题节点保持稳定 ID。点击或键盘选择节点后，滚动容器把节点置于视野中央，并只强调其关联事件；多人同场仍连接到同一个互动事件节点，不生成两两好友关系。
4. 根据教育工作区中已确认的“第N周”校历边界提供“本学期”，保留自定义起止日期与“全部时间”。没有周次时不猜测学期日期。
5. 知识图谱使用“学生 / 学习记录 / 知识点”，人际互动网络使用“学生 / 互动事件 / 活动主题”。空状态保留对话记录入口。

## 验收

- 两名同名学生使用不同 ID，分别进入详情且网络不串档。
- 一次三人同场互动只产生一个事件节点；点击同伴节点后目标居中并显示关联事件。
- 45条以上记录分三层加载，显示20→40→上限或总数，筛选后重新从第一层开始。
- 点击“本学期”只显示导入周次范围内记录；自定义日期和全部时间可往返。
- 修改、历史恢复和删除后，列表、网络节点、计数和来源详情同步；刷新与服务重启保持。
- 61人名单分页、学生详情双入口和窄窗口布局复核通过。隔离记录明确标注为测试，不写真实学生档案。
