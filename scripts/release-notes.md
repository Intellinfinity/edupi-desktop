- 家校观察仅展示明确学生身份、来源和修订历史。未核实的监护身份、关系好坏与 G5 授权不会由一条记录推断。
- 备课任务读取 Core 的真实阶段、attempt、历史和取消/重试权限；未知子代理数量和总步骤不编造。来源变化后旧任务 revision 拒绝继续操作。
- 桌面端修复重复发送、提醒恢复、授权状态和过期事项的前台时效；工作区与“今天”按当前事项呈现，历史仍可查找。

- Core 只自动续接可安全执行的请求；自然改期与取消在本候选中不自动改写既有任务，需在后续审核入口完成闭环。
- 新 ICS 日历默认只接入材料；教师预览文件内事项并明确确认后，才按预览指纹将日程写入 Core。过期预览与缺少桌面授权均拒绝采用。
- DOCX 首次接入同样只保存材料；可核对的日程提案由教师另行明确采用，缺失时区等来源问题保持待审。已有来源修订仍使用原指纹绑定。
