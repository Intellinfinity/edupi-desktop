EduPi Desktop 0.3.48。

- Core 固定 `453e303`（#213）。G1 默认关闭；教师明确启用单班单科及当前来源授权后，才允许在桌面后台生成内部待审草稿，最多 12 次已核算模型调用。旧授权须先停止再重新启用；不会自动发给学生或家长。
- 重新启用后，旧草稿若因授权版本变化而来源失效，会保留待审并提示教师核对，不会再次自动调用模型；权限拒绝、额度耗尽及材料未确认仍阻止启用。
- Windows G1 仅在独立受保护数据根、Safe Mode 与安装资源原生来源守护均通过时作为隔离试用启动；普通模式继续关闭。系统通知点击、真实跨到期睡眠和安装版教师反馈仍需正式安装后逐项验收。
- G2、G3、G4 Live 默认关闭；G5 监护关系、未核实材料及课次/学期归属不当作已验证。
- macOS Apple Silicon DMG 使用 Developer ID 签名与公证；Windows x64 提供 NSIS 安装程序，Linux x64 提供 Debian 包与 AppImage。
- 带 updater 插件的旧版可在应用内检查、下载、验签、安装并重启。v0.3.29 仍需一次手动安装新版。
